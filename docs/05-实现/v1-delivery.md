## 验证证据

```text
pnpm check             ✅ typecheck + lint + 165 单测 + token drift
pnpm build             ✅ production build
pnpm audit --prod      ✅ No known vulnerabilities found
playwright --workers=1 ✅ 24 / 24 E2E（无重试）
```

E2E 覆盖：

- Auth / 权限：短信、第三方 mock 登录、启动页、相册授权。
- CL-01 建档、CL-02 诊断处方、CL-03 训练错因、CL-04 模考重诊断、CL-05 申论重写、CL-07 周复盘、CL-08 选岗、CL-09 会员。
- 后台 RBAC：员工登录、越权 403、审计入库、AI 服务端评测、工单入库、职位表导入。
- 安全回归：登录页不暴露任何默认口令、后台登录节流达到上限返回 429 且锁定期内正确口令仍被拒。
- 训练持久化：未提交选择与题级用时在重载后恢复，题级时间不被会话平均化。
- V1 外部数据导入、偏好/隐私实际控件。

> 在 Windows 环境中，E2E 必须保持 `--workers=1` 串行运行；并行时生产服务器偶发 ChunkLoadError，串行结果稳定。

## 真实度边界

V1 交互、状态机、确定性规则、SQLite 数据和服务端 API 已实现。以下接入点保留 mock adapter，且未对外宣称真实上线：

1. 短信下发：真实服务商适配器待接入。未配置服务商且未显式开启本地 mock 时，发送接口 503 失败关闭，绝不回显验证码。
2. 微信/Apple 身份与支付/退款渠道：仍为 mock adapter，第三方身份由服务端按授权码校验，不接受客户端自报身份。
3. AI Provider：申论/诊断/解析使用确定性引擎；Rubric 与证据链真实可运行，模型调用可替换。质量候选池只使用脱敏摘录与可验证来源。
4. 职位与历史数据：自带种子显式标注为演示数据且界面提示不可作为报名依据；正式数据须经 `/admin/positions` 导入官方职位表。
5. 预测为历史区间，不展示上岸概率或精确承诺。
6. 真机性能、真实用户盲测仍是发布前验证，不影响功能清单 V1 完成状态。
